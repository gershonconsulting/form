WHAT IT IS
"Onboarding AI Form": a client types their website (+ optional LinkedIn) -> /api/research (Anthropic Messages API + web
search) pre-fills the intake -> client reviews every field, uploads the validated quote, signs -> /api/submit stores the
row (+ quote file attachment) in Airtable and emails a notification through Resend.
Single page: app/page.tsx -> components/GershonOnboarding.tsx (all UI). API routes in app/api/*. Helpers in lib/*.

2026-10-23 nightly (Cloudflare build fix)
✅ Cloudflare Pages builds of this PR failed at the install step. Two causes:
   1. package-lock.json was the old 0.1.0 app's lockfile (Supabase, next 14.1.0), so `npm ci` refused to run.
   2. @cloudflare/next-on-pages "^1.13.5" now resolves to 1.13.16, which requires next >= 14.3; this app uses next 14.2.15,
      so even `npm install` stopped with ERESOLVE.
   Fix: package.json pins @cloudflare/next-on-pages to 1.13.15 (last version that accepts next 14.2), and the stale
   lockfile is removed. A fresh lockfile is 374 KB, too large for the upload tool, so it is not committed yet.
✅ Verified locally with Node 20.11.1 / npm 10.2.4: no-lockfile `npm install` + `npx @cloudflare/next-on-pages` builds
   (5 edge routes, prerendered /); with a freshly generated lockfile `npm ci && npm run build` also passes.
